Adding a project and preparing presentation files

Recommended folder layout: keep index.html beside decks/ (PDFs), original-files/ (optional PPTX downloads), and presentations/project-id/ (converted slide images). The supplied wedding images are currently in Rush_Socials_Wedding_Pitch_Deck/.

PowerPoint: export the deck to PDF with Microsoft PowerPoint or LibreOffice Impress, then export each PDF page as a high-quality JPG or PNG. For example, with Poppler installed, run pdftoppm -jpeg -r 150 input.pdf presentations/project-id/slide; rename output pages to slide-01.jpg, slide-02.jpg, etc. Add the image paths, title, description, category, and optional original PPTX path to the projects object in this file. Browsers do not render PPTX files directly.

PDF: on the project entry, set pdf: "decks/name.pdf" and format: "PDF presentation". PDF page rendering and thumbnails use PDF.js from a CDN when a PDF is opened, so that feature needs an internet connection; a direct link to the original PDF remains available as a fallback.

New portfolio card: duplicate a project card in the work section with a unique data-deck key, then add a matching entry to projects with its title, category, description, cover, and either pdf or type: "images" plus a slides array. Set originalPptx if the source file may be downloaded. Keep all paths relative to this HTML file.

Testing: use a local web server (for example, VS Code Live Server) and deploy this file with its asset folders together. Opening HTML as file:// may prevent PDF.js or browsers from loading local assets correctly. The static site itself has no backend.
